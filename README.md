# PASTOR ABAYOMI BIBLE STORIES DAILY DEVOTIONALS — 2026

GitHub/Vercel-ready static devotional website.

- 365 dated devotionals, 1 January–31 December 2026
- Adult-focused detailed reflections
- Each day: Bible reading reference, detailed devotional prose, prayer, memory verse reference, hymn suggestion and focus point
- No children/teen/family discussion sections in this edition
- No Supabase required for public reading
- 12 monthly reading data files to keep the repository compact
- Official PASTOR ABAYOMI BIBLE STORIES branding
